# TYmemo

달력·할 일·메모를 캐릭터가 말풍선으로 알려 주는 윈도우 PC 프로그램입니다. 안드로이드 앱과 같은 계정으로 동기화됩니다.

## 내려받기

**최신 설치 파일: [tymemo.exe](https://github.com/atylove7700-sys/tymemo/releases/latest/download/tymemo.exe)**

내려받아 실행하면 설치됩니다 (관리자 권한 필요 없음). 이미 설치돼 있으면 기록은 그대로 두고 업그레이드됩니다.

지난 버전: [Releases](https://github.com/atylove7700-sys/tymemo/releases)
